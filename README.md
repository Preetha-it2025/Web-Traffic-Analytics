# Web Traffic Analytics

## Project Overview
This project analyzes sample website traffic data to understand visitor behavior, page views, session duration, traffic sources, and exit pages.

## Objectives
- Analyze website traffic sources.
- Calculate total page views and average session duration.
- Identify single-page sessions.
- Analyze conversion rates.
- Understand landing and exit page combinations.
- Identify common exit pages.

## Tools Used
- Google Sheets
- Data Analysis
- Charts and Formulas

## Dataset
This project uses a synthetic practice dataset containing 12 sample website sessions.

The dataset includes:
- Session ID
- Traffic Source
- Landing Page
- Pages Viewed
- Session Duration
- Exit Page
- Conversion Status

## Key Findings
- Total Sessions: 12
- Total Page Views: 40
- Average Session Duration: 137.5 seconds
- Single-Page Sessions: 2
- Converted Sessions: 6
- Conversion Rate: 50%
- Most Common Exit Page: Products (3 sessions)

## Analysis Performed
1. Traffic Source Analysis
2. Session Analysis
3. Conversion Analysis
4. Landing-to-Exit Analysis
5. Exit Page Analysis
